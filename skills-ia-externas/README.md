# Skills de IA — pacotes externos

[[Cerebro|<- Cerebro]]

Aqui ficam guardados (só como referência/backup) os pacotes de habilidades de IA que estavam na pasta "SKILL Agent" da sua Mesa. Servem de apoio pra quando formos criar o app — principalmente os de design e programação.

Isso aqui é conteúdo genérico baixado da internet (não é seu, não tem dado da PM nem do CredPlus) — guardado só pra consulta.

- `superpowers/` — método completo de desenvolvimento de software pra IA seguir (14 habilidades)
- `agent-skills/` — 25 habilidades de engenharia de software nível sênior
- `marketingskills/` — 50 habilidades de marketing (copy, SEO, growth)
- `caveman/` — 21 habilidades pra IA escrever de forma mais econômica
- `browser-use/` — 6 habilidades de automação de navegador
- `design-futurista-3d/` — 1 habilidade de design (dashboards/apresentações estilo futurista 3D) — essa é a mais ligada ao app que vamos criar
- `andrej-karpathy-skills/` — 1 habilidade, boas práticas gerais de código
- `defuddle-skill/` — 1 habilidade, extrair texto limpo de páginas web
- `skills-composio/` — 1 habilidade, integração com Composio

Cada pasta tem o `README-original.md` (explicação de quem criou) e a subpasta `skills/` (ou `SKILL.md`) com o conteúdo de verdade.

**Importante:** guardar aqui é só cópia de referência. Pra essas habilidades funcionarem de verdade dentro do Claude, precisam ser instaladas — isso é feito fora daqui (veja pendência abaixo).
