# Biblioteca de Legislacao

Guarde cada PDF na pasta correspondente:

- `federal/` — leis e decretos federais.
- `tocantins/` — normas estaduais do Tocantins.
- `interministerial/` — portarias, resoluções e normas interministeriais.
- `municipal/` — normas municipais.

Ao adicionar um arquivo, use nome claro: `AAAA-MM-DD - Tipo - Numero - Assunto.pdf`.
