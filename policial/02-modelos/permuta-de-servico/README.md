# Permuta de Serviço

Modelo em Word para pedidos e registros de permuta de serviço.

## Arquivo

- `PERMUTA-DE-SERVICO-NOVO-MODELO.docx` (guardado somente neste cofre local)

## Uso

Use este arquivo como referência de estrutura e linguagem. Antes de gerar ou
usar uma nova permuta, confira datas, nomes, unidades, escalas e assinaturas.

O arquivo atual tem nomes e identificações funcionais reais. Por segurança,
ele não é enviado ao GitHub. Para sincronizar uma versão futura, primeiro
crie uma cópia anonimizando nomes, matrículas, datas, escalas e assinaturas.
