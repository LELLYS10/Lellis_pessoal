# Modelos Profissionais

Aqui entram modelos sem dados reais, para a Hermes aprender o padrão de redação.

- `ocorrencias/`
- `oficios/`
- `relatorios/`
- `parte-diaria/`
- `whatsapp/`
- `permuta-de-servico/`

Antes de guardar um modelo, retire nomes, CPF, telefones, placas, endereços e números de processos reais.
