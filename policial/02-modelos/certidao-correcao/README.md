titulo: Certidão de correção de campo — como usar
status: ativo
---

Modelo genérico para corrigir erro material em qualquer campo de um documento já lavrado (valor de multa, CPF, data, etc.), sempre no formato "onde se lê / leia-se".

- `MODELO-CERTIDAO-CORRECAO-DE-CAMPO.md` — texto-base genérico (qualquer campo)
- `MODELO-CERTIDAO-CORRECAO-CPF.pdf` — exemplo pronto em PDF, aplicado ao campo CPF

Pra gerar uma certidão nova: copie o texto-base, troque [NOME DO CAMPO] pelo campo que precisa corrigir (ex.: CPF, valor da multa, data), e preencha o "onde se lê / leia-se" com o dado errado e o dado certo.
